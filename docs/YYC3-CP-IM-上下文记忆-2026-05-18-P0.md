### 设计评估

当前架构已具备 **WS优先 + 降级模拟** 的双模式设计：

- `useWebSocketData` 已实现：WS连接成功 → 真实数据 / WS失败 → 模拟数据
- `useBigModelSDK` 已实现：有API Key → 真实API / 无Key → Mock
- `isSimulated` 标志位已暴露给UI

**结论**: 架构设计合理，核心问题是确保后端服务可用后关闭模拟降级。
