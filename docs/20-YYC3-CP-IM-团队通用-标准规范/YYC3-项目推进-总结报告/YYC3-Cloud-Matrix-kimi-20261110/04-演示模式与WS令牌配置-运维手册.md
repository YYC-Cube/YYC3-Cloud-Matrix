# 🛠️ 演示模式与 WS 令牌配置 · 运维手册

## 一、演示模式总开关（demoMode）

### 1.1 语义

| 状态 | 行为 |
| ---- | ---- |
| **关闭（生产默认）** | 所有模拟数据源不产出编造数据；无真实来源的模块显示空态或配置引导 |
| **开启** | 巡查 / AI 诊断 / 报表导出 / 数据库管理 / 操作中心 / SDK 对话 / AI 助理使用内置模拟数据，供演示与开发调试 |

### 1.2 配置入口

「更多 → 系统设置 → 显示与界面 → 演示模式」开关。

- 读写 Settings SSOT（`useSettingsSSOT.toggles.demoMode`），持久化于 localStorage `yyc3-settings-ssot`
- 切换即时生效，无需重启；多标签页经 BroadcastChannel 同步

### 1.3 挂接的模拟源清单

| 模块 | 关闭态行为 |
| ---- | ---- |
| 巡查管理（usePatrol） | 手动/自动巡查拦截 + toast 引导；历史列表空（持久化保留） |
| AI 诊断（useAIDiagnostics） | 诊断启动拦截；历史空 |
| 报表导出（useReportExporter） | 生成拦截；报表历史空 |
| 数据库管理（useLocalDatabase） | 全部 Mock 回退分支拦截，仅保留真实 API 路径；不可达如实报错 |
| 操作中心（useOperationCenter） | 操作/模板执行拦截；日志空 |
| SDK 对话（useBigModelSDK） | 未配置 API Key 时返回配置引导；连接测试不假阳性 |
| AI 智能助理（AIAssistant/useChat） | 本地 Mock 回复替换为配置引导 |
| 监控数据（useWebSocketData） | WS 不可达时不回退模拟器，如实「已断开」；首屏初值空态 |

### 1.4 注意事项

- 演示期产生的持久化数据（巡查历史、诊断历史、报表历史）**不会被删除**，关闭开关仅隐藏；重新开启即恢复
- 生产环境**必须保持关闭**；关闭态行为由 `src/app/__tests__/demo-mode-off.test.ts`（11 用例）锁定

## 二、WS 通道鉴权（yyc3-agent）

### 2.1 架构

```
浏览器前端 ──ws://127.0.0.1:3113/ws?token=<agent-token>──▶ yyc3-agent
```

- 未携带或错误令牌：WS upgrade 返回 **401** 并断开（服务端日志记录拒绝来源）
- 比较使用 `crypto.timingSafeEqual`（防时序侧信道）

### 2.2 令牌来源（agent 端优先级）

| 优先级 | 来源 |
| ---- | ---- |
| 1 | 环境变量 `PMO_AGENT_TOKEN` |
| 2 | 文件 `~/.yyc3-cloud-matrix/agent-token`（权限 0600） |
| 3 | 文件不存在时**自动生成** 48 位 hex 并写入该文件 |

查看当前令牌：

```bash
cat ~/.yyc3-cloud-matrix/agent-token
```

### 2.3 前端配置

「更多 → 系统设置 → WebSocket → WS 访问令牌」粘贴同一令牌（密文输入，可切换显隐）。

- 留空 = 不携带令牌（agent 启用鉴权时将连接失败，页面显示「已断开」）
- 保存后下一次 WS 连接（自动重连）即生效

### 2.4 网络暴露面

| 配置 | 适用场景 |
| ---- | ---- |
| `PMO_AGENT_HOST=127.0.0.1`（**默认**） | 本机自用，仅回环可连 |
| `PMO_AGENT_HOST=0.0.0.0` | 局域网多机接入（`deploy/com.yyc3.agent.plist` 显式启用），由令牌鉴权兜底 |

### 2.5 排障

| 现象 | 排查 |
| ---- | ---- |
| 页面「已断开」 | ① `curl http://127.0.0.1:3113/healthz` 确认 agent 存活；② 前端令牌与 `~/.yyc3-cloud-matrix/agent-token` 是否一致；③ agent 日志是否出现「拒绝未授权 WS 连接」 |
| 令牌丢失 | 删除 `~/.yyc3-cloud-matrix/agent-token` 后重启 agent，自动生成新令牌并重新填入前端 |
| 修改令牌 | 设置 `PMO_AGENT_TOKEN` 环境变量重启 agent，或改写 token 文件后重启 |
