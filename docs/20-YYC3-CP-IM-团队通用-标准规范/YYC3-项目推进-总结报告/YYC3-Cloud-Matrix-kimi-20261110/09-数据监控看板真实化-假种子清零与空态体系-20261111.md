## 二、落地方案

### node-slice（假节点清零）
- `DEFAULT_NODES` → `[]`；`resetNodes` → 空态
- persist `version: 1` + migrate：按 ID（GPU-A100-01~08 / GPU-H100-01）一次性清除历史假节点，保留用户真实添加
- 补 `onRehydrateStorage` 重算 derived（修复 partialize 只存 nodes 导致派生统计陈旧的潜在 bug）

### metrics-slice（可编辑项零硬编码）
- 三组 `DEFAULT_*` → 空数组；`resetAll` → 全空
- persist migrate：按 ID（mp-1~5 / md-1~5 / rd-1~6）清除假条目，保留用户自建
- 编辑入口不变：系统管理 → 数据总控（DataEditorPanel）自行维护

### useWebSocketData（演示数据归位 demoMode）
- 演示种子迁入 hook 内 `SIM_DEMO_NODES`（5 个 DEMO-GPU-* 节点），仅 demoMode 模拟器可达
- `runSimulation` 基准：slice 非空用 slice，空则用演示种子 —— demoMode 关闭时绝不产出

### Dashboard.tsx（空态体系）
- 6 处 `?? 假值` → `0 / "-"`；4 个假趋势标签 → `"-"` 且趋势徽标自动隐藏
- 预测图：历史不足返回空 + `prediction-empty` 空态
- 模型分布：真连/非真连统一空态 `model-dist-empty`
- 雷达/性能图：新增共享 `ChartEmpty` 组件（`chart-empty`）
- i18n 新增 `monitor.noChartData` / `monitor.noPredictionData` 双语
