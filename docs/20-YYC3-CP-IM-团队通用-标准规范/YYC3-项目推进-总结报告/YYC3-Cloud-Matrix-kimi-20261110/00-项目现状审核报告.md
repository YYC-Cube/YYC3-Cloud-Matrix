## 一、架构概览（代码实证，非文档转述）

### 1.1 五条数据通道现状

| # | 通道 | 端点 / 载体 | 生产消费面 | 状态 |
| --- | ---- | ----------- | ---------- | ---- |
| 1 | **WS 实时通道** | `ws://localhost:3113/ws`（`agent/yyc3-agent.mjs`） | 7 个组件（Dashboard 系 / FollowUpPanel / AlertRulesPanel / PatrolDashboard / AIAssistant / AIDiagnostics / Layout） | ✅ **已真实化**（CPU/内存/磁盘/Ollama 实测，告警回放） |
| 2 | **Ollama 推理代理** | `:3118 /api/v1/llm/ollama/*`（`deploy/server.mjs`） | SDK 对话 / 模型管理 | ✅ 真实 |
| 3 | **DB Proxy 通道** | `localhost:3299` → 本机 PostgreSQL（`lib/family-db-bridge.ts`） | `useDbData.ts` → **生产消费者 = 0** | 🔴 **死链路**：服务端不存在于本仓库，且违背无后端原则（已标记 @deprecated） |
| 4 | **Supabase 云通道** | 云端 BaaS | 登录认证（可选） | ⚠️ 与「本地化无后端」原则存在张力；Ghost Mode 兜底合规 |
| 5 | **本地持久化** | localStorage（zustand persist × 18 slices）+ IndexedDB + PWA | 全局 | ✅ 符合《安全隔离核心设计》 |

### 1.2 状态层拓扑（实证）

```
store/slices/（18 个 slice，zustand persist）── 生产 SSOT
  ├─ node-slice          节点域（WS 权威快照，本轮已真实化）
  ├─ follow-up-slice     告警工单域（本轮清空假种子，改真实事件摄入）
  ├─ metrics-slice       指标域（DEFAULT_MODEL_DIST 假种子，真连态已被真实聚合替代）
  ├─ log-slice           日志域（DEFAULT_LOGS 假种子残留）
  ├─ app-slice           应用域（recentOps 假操作流种子残留）
  └─ ... 其余 13 个
stores/
  ├─ global-store.ts     v4.0.0 active — 聚合适配层（useAlerts 桥接 follow-up-slice）
  └─ dashboard-stores.ts Legacy — 生产零引用，仅 2 个测试文件使用
lib/data-bus.ts          消息总线 + 节点合并引擎（内含 @deprecated WS 引擎区，计划 v3.0 删除）
```

### 1.3 路由现状

- 实际：单文件扁平路由 `src/app/routes.tsx`（~40 条），仅 `ai-family` 与 `dev` 有模块级 `routes.tsx`

## 二、硬编码违例清单（「禁止硬编码」政策审核）

### 2.1 已修复（本轮）

| 违例 | 位置 | 修复方式 |
| ---- | ---- | -------- |
| 通知铃铛 badge 写死 `3` + 3 条虚构通知（GPU-A100-03 等） | `modules/shared/TopBar.tsx` | 接入告警工单域 SSOT，空态显示「暂无通知」 |
| `DEFAULT_FOLLOWUPS` 假工单种子（温度告警/模型升级） | `store/slices/follow-up-slice.ts` | 清空种子，新增 `ingestWSAlert` 真实事件幂等摄入 |
| 真实 WS 告警只进组件本地 state，刷新即丢 | `hooks/useWebSocketData.ts` | alert 消息同步写入 follow-up-slice 持久化 |
| 边沿告警一次性广播，后连入客户端永久错过 | `agent/yyc3-agent.mjs` | 新增活跃告警条件快照，客户端连入时回放 |
| `addFollowUp` 同毫秒 ID 碰撞（`fu-${Date.now()}`） | `store/slices/follow-up-slice.ts` | ID 追加随机段（真实 bug：completeFollowUp 曾误伤同 ID 工单） |
