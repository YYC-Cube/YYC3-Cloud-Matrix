### 2. `src/app/hooks/useSecurityMonitor.ts`（v1 → v2 全量重写）
- `startScan` 改 async 分支：demoMode 开 = 演示生成器（保留）；**demoMode 关（默认）= 真实浏览器采集**
- 真实采集器一览：

| 采集器 | 真实数据源 | 诚实标注 |
|---|---|---|
| `realCSP` | 解析 `meta[http-equiv="Content-Security-Policy"]`，`unsafe-inline/eval`/通配符标 warn，score=100−15×warn | 响应头 CSP 页面上下文不可读 → recommendations 注明需服务端审计 |
| `realCookie` | `document.cookie` 仅统计数量 | Secure/HttpOnly/SameSite JS 不可读 → 单条诚实说明，score=−1 不参与总评 |
| `realSensitive` | 真实枚举 localStorage/sessionStorage 键，键名匹配 `token|secret|password|apikey|credential` 标 warning，附实际大小 KB | 只评估键名，不读取值内容 |
| `realPerformance` | `PerformanceResourceTiming` / `NavigationTiming` 真实条目；img 懒加载按真实 DOM 统计 | jsBundles 取 script/link 真实 transferSize/decodedBodySize |
| `realMemory` | `performance.memory`（Chromium）+ `querySelectorAll('*').length` 真实 DOM 节点数 | listeners/timers JS 不可测 → −1，UI 显示 N/A；trend 为单点真实采样 |
| `realVitals` | navigation entry TTFB、LCP、layout-shift CLS | FID/INP 需用户交互无法回溯，不产出 |
| `realDevice` | WebGL `WEBGL_debug_renderer_info` 真实 GPU；navigator 全真实值 | 删除硬编码 "Apple M4 Max GPU (Simulated)" |
| `realNetwork` | `navigator.connection` + `navigator.onLine` | 不支持的浏览器字段为 0/unknown |
| `realBrowser` | UA 正则解析 + 12 项特性真实探测（`'serviceWorker' in navigator` 等） | upgradeNeeded 按真实不支持数量判定 |
| `realDataManagement` | localStorage/sessionStorage 体积按键值 UTF-16 长度实算；`navigator.storage.estimate()` 取 idb/caches | expiredItems 无 TTL 体系如实为 0；lastBackup 读真实备份时间戳 |

- 总评分：仅对有真实评分能力的项求均值（过滤 score=−1）
- `cleanupData` 真实化：cache → `caches.keys()` 逐个 `caches.delete`；privacy → `sessionStorage.clear()`；清理后重算真实体积
